Car Hub is a website made for people who enjoy automobiles. Here, you can explore different models, check basic specifications and compare your favourite cars.

This project uses HTML for the page structure, CSS for the design and JavaScript for interactive features. It is a simple example of how a website can make information more interesting.

  • 🏎️ Sports cars and supercars
  • 🧭 Dedicated off-road, SUV and sedan collections
  • 🔍 Simple search and filters
  • ❤️ A personal favourites list
  • ⚡ Side-by-side car comparison
